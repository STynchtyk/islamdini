# Islamdidi

## Запуск

Нужен Node.js 18 или новее. В папке сайта выполните:

```powershell
node server.js
```

Затем откройте `http://127.0.0.1:4173`.

Сервер получает расписание из официального календаря КМДБ и передаёт его сайту по адресу `/api/prayer`. Полный официальный список — 115 населённых пунктов Кыргызстана — загружается через `/api/locations`, поэтому в меню есть, например, Кызыл-Кыя, Ноокат и Кара-Суу. Это нужно потому, что официальный сервис не разрешает прямой запрос из браузера. Для временного сбоя предусмотрен резервный астрономический расчёт по координатам выбранного города и сохранённое расписание на текущую дату.

Расписание обновляется при смене даты в Бишкеке, возвращении на вкладку, восстановлении соединения, вручную кнопкой повторной загрузки и периодически в течение дня. Даты до 31 декабря 2040 года проверены через официальный источник.

В меню также добавлены города с предоставленного списка: Мекка, Мадина, города России, Казахстана, Узбекистана, Азербайджана, Таджикистана, ОАЭ, Туркменистана и Республики Корея. Для них сайт использует динамический астрономический расчёт по координатам и часовому поясу выбранного города; он не подменяет официальный календарь КМДБ для Кыргызстана.

## Материалы

В `public/data/materials.json` добавлены публичные статьи из переданной резервной копии. Поиск находит совпадения по заголовку, рубрике, тегам и полному тексту; исходный архив посетителю не показывается. Список выводится порциями по 24 карточки, чтобы большая библиотека не замедляла страницу.

Для повторного импорта SQL-резервной копии используйте:

```powershell
node scripts/import-legacy-materials.mjs <source.sql> public/data/materials.json
```

Импортёр читает только публичные записи `dle_post` и названия категорий из `dle_category`; учётные записи, журналы, настройки и другие таблицы не переносятся. HTML из старых записей очищается до текста перед публикацией.
